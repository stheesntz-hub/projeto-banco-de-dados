# 🚗 Concessionária Stheka

Sistema de gerenciamento de uma concessionária de veículos desenvolvido em Python com Streamlit e Firebase.

## 🛠️ Tecnologias utilizadas

* Python
* Streamlit
* Firebase / Firestore

## 📋 Funcionalidades

* Cadastro e consulta de clientes
* Cadastro e consulta de funcionários
* Consulta de veículos
* Funcionalidades relacionadas à compra de veículos

## ▶️ Como executar

Instale as dependências:

```bash
python -m pip install streamlit firebase-admin python-dotenv
```

Configure as credenciais do Firebase localmente e execute:

```bash
streamlit run app.py
```
